# Secullum Ponto - Landing Page

Landing page da Impacto Tecnologia para Secullum Ponto/REP.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub (ex: `secullum-ponto-lp`), público.
2. Suba este arquivo `index.html` (e o `README.md`) para a raiz do repositório.
3. Em **Settings > Pages**, em "Build and deployment", selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Aguarde 1-2 minutos. O site fica em `https://<seu-usuario>.github.io/<nome-do-repo>/`.

Esse `index.html` é autocontido (todos os recursos ficam embutidos e são "desempacotados" via JS ao carregar) — não precisa de mais nenhum arquivo além dele.
